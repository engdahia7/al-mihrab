# المحراب — مواقيت الصلاة والمصحف والأذكار الموثقة (`Al-Mihrab`)

منصة إسلامية مرجعية متكاملة تعمل كتطبيق ويب تقدمي (**PWA**) وتطبيق أندرويد أصلي (**TWA / Google Play Console**) مع دعم كامل للعمل بدون إنترنت (**Offline-First**).

---

## أبرز المميزات

1. **مواقيت الصلاة الفلكية الدقيقة**:
   - حسابات فلكية محلية عالية الدقة وفق التقاويم المعتمدة (أم القرى، رابطة العالم الإسلامي، الهيئة المصرية، كراتشي، أمريكا الشمالية، دبي/الخليج).
   - تحديد الموقع الجغرافي تلقائياً عبر **GPS** مع جلب اسم المدينة بالعربية، ونظام احتياطي ذكي عبر الشبكة عند تعذر الـ GPS.
   - منبه الأذان الصوتي، تنبيه ما قبل الإقامة، ووضع السكينة التلقائي وقت الصلاة.
2. **المصحف الشريف بالرسم العثماني والتلاوة والحفظ**:
   - صفحات مصحف المدينة النبوية (**١ إلى ٦٠٤**) بالرسم العثماني مع أوضاع القراءة (الورقي الكلاسيكي، الرق الدافئ، الوضع الليلي).
   - **خيار الحفظ عند آية معينة والاستكمال لاحقاً**: تثبيت موضع التوقف عند أي آية بضغطة واحدة والعودة الفورية إليها مع تظليلها التلقائي.
   - **البحث الفوري في الآيات بدون تشكيل**: البحث بأي كلمة أو جزء من آية دون اشتراط الحركات أو الهمزات.
   - **التفسير الميسر ومعاني الكلمات وبطاقة المشاركة**: نافذة هادئة عند النقر على الآية تعرض التفسير الميسر أو الجلالين، معاني المفردات، وتوليد بطاقة مصورة عالية الدقة للآية مع تفسيرها.
   - **مُحفّظ ومكرر الآيات**: تحديد نطاق آيات وتكرار كل آية والمقطع الكامل بعدد مرات مخصص مع أشهر القراء.
3. **بوصلة القبلة التفاعلية والمساجد القريبة**:
   - حساب زاوية القبلة بمعادلة الدائرة العظمى الكروية، مع دعم الحساس المغناطيسي الحي للهاتف (`deviceorientation`) ومعايرة يدوية للأجهزة المكتبية، وخريطة المساجد القريبة عبر OpenStreetMap.
4. **الأذكار الموثقة، الأدعية، والمواريث الشرعية**:
   - أذكار الصباح والمساء وبعد الصلاة من «حصن المسلم» مع عداد تسبيح تفاعلي، وحاسبة الفرائض والمواريث الشرعية وزكاة المال والذهب.

## التشغيل المحلي والاختبار

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير (المنفذ 3000)
npm run dev

# تشغيل جميع الاختبارات البرمجية (Unit Tests)
npm test

# فحص الأنواع البرمجية (TypeScript)
npm run lint

# بناء النسخة الإنتاجية الجاهزة للنشر (تُحفظ في مجلد dist/)
npm run build
```

## أولاً: خطوات رفع المشروع على GitHub

المشروع مجهز بالكامل بملف `.gitignore` نظيف وملف التشغيل التلقائي `.github/workflows/ci-deploy.yml`:

```bash
# 1. تهيئة مستودع Git المحلي (إن لم يكن مهيأً)
git init
git branch -M main

# 2. إضافة جميع الملفات وتوثيق التغييرات
git add .
git commit -m "feat: release Al-Mihrab v1.0.0 ready for GitHub and Google Play Console"

# 3. ربط المستودع بحسابك على GitHub ورفع الكود
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/al-mihrab.git
git push -u origin main
```

- لتفعيل النشر التلقائي عبر **GitHub Pages**: ادخل إلى إعدادات المستودع في GitHub ثم **Settings → Pages**، واختر **Source: GitHub Actions**. سيقوم ملف `.github/workflows/ci-deploy.yml` بفحص الكود وتشغيل الاختبارات ونشر التطبيق تلقائياً عند كل `push`.

## ثانياً: خطوات النشر على Google Play Console و Google Search Console

راجع الدليل التفصيلي الكامل في ملف **[`GOOGLE_CONSOLE_GUIDE.md`](./GOOGLE_CONSOLE_GUIDE.md)** المرفق في جذر المشروع، والذي يشرح خطوة بخطوة:
1. توليد حزمة أندرويد الرسمية (`.aab` - Android App Bundle) عبر **PWABuilder** أو **Bubblewrap CLI** (`twa-manifest.json`).
2. ربط بصمة التوقيع الرقمي `SHA-256` في ملف **`public/.well-known/assetlinks.json`** لإخفاء شريط المتصفح واعتماد ملكية النطاق.
3. إعداد صفحة المتجر في **Google Play Console**، ورابط سياسة الخصوصية الجاهز **`/privacy-policy.html`**، وإجابات نموذج **أمان البيانات (Data Safety)**.
4. توثيق الموقع وإرسال خريطة الموقع **`/sitemap.xml`** في **Google Search Console**.
